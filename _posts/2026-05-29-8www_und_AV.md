# 🌐 WWW und Audio/Video – Cheat Sheet (Kapitel 8)

## 1. World Wide Web (WWW)

### 🌍 URL (Uniform Resource Locator)
- Aufbau:
```

<scheme>://<host>:<port>/<path>?<search>

```
- Beispiel:
```

<http://www.example.com/index.html>

```

👉 definiert **Ort + Zugriffsmethode**   

---

## 2. HTML, XML

### 📄 HTML
- Beschreibung von Webseiten (Darstellung)
- Tags:
  - `<B>`, `<I>`, etc.

### 📦 XML
- strukturierte Datenbeschreibung
- XML Schema definiert Struktur

👉 wichtig für Datenaustausch und Webservices   

---

## 3. HTTP (Hypertext Transfer Protocol)

### 📡 Eigenschaften
- Request/Response Modell
- basiert auf TCP (Port 80)
- zustandslos  

---

### 📥 HTTP Methoden
- `GET` → Daten holen
- `POST` → Daten senden
- `HEAD` → nur Header
- `PUT`, `DELETE`

---

### 📦 Nachrichtenformat

#### Request:
```

GET /index.html HTTP/1.1
Host: ...
Header...

```

#### Response:
```

HTTP/1.1 200 OK
Header...
Body...

```

👉 Aufbau:
```

\[Startlinie]\[Header]\[Leerzeile]\[Body]

```
  

---

## 4. HTTP Versionen

### 🟢 HTTP/1.0
- **nicht persistent**
- jede Anfrage → neue TCP-Verbindung

---

### 🔵 HTTP/1.1
- **persistent connections**
- mehrere Requests pro Verbindung
- Pipelining

---

### 🟣 HTTP/2
- Multiplexing (mehrere Streams gleichzeitig)
- Header-Kompression
- Server Push

---

### 🟠 HTTP/3 (QUIC)
- basiert auf UDP
- schneller Verbindungsaufbau
- kein Head-of-Line Blocking
- integrierte Verschlüsselung (TLS 1.3)
